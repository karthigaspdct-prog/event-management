# EventEase - College Event Management

A web app for college event registration, ticket generation with QR code, and attendance tracking. Built with plain HTML, CSS and JavaScript. No installation or backend needed.

## Features
- View upcoming college events with seats left
- Organizers can add new events
- Student registration with name, roll number, department and email
- Unique ticket ID and QR code for every registration
- Duplicate registration check and seat limit check
- Find a ticket using its ID
- Attendance tracking by entering the ticket ID
- Attendance dashboard: registered, present, absent and percentage
- Data saved in the browser (localStorage)

## Tech Stack
HTML5, CSS3, JavaScript (ES6), qrcodejs library for QR codes

## How to Run
1. Download or clone this repository
2. Open `index.html` in any browser (internet needed only to show QR codes)
